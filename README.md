# MimicType

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Platform: Linux](https://img.shields.io/badge/Platform-Linux-orange.svg)]()
[![Python: 3.10+](https://img.shields.io/badge/Python-3.10%2B-brightgreen.svg)]()

**MimicType** — низкоуровневая Linux-утилита посимвольного ввода текста из буфера обмена с реалистичной биомеханической моделью печати человека (Keystroke Dynamics).

Генерирует нативные аппаратные события ввода через виртуальное устройство ядра Linux `/dev/uinput` (`python-evdev`). Браузеры (Google Chrome, Firefox) и веб-приложения воспринимают ввод как стандартную физическую клавиатуру с флагом `event.isTrusted: true`.

---

## Ключевые возможности

- 🧠 **Keystroke Dynamics**:
  - Логнормальное моделирование времени удержания клавиш (*Dwell Time*).
  - Биомеханический расчёт времени перехода (*Flight Time*) для диграфов и триграфов с учётом расстояния между клавишами на физической клавиатуре.
  - Адаптивный ритм: когнитивные паузы перед знаками препинания, переводами строк и ключевыми словами кода.
- 🖐️ **Имитация человеческих опечаток**:
  - Случайные ошибки на основе физического графа смежности клавиш (*Fat-finger errors*).
  - Моделирование моторной инерции и последующего исправления через `Backspace`.
- ⚡ **Низкоуровневая интеграция (`uinput`)**:
  - Нативные аппаратные скан-коды и таймстампы ядра.
  - `event.isTrusted: true` в DOM браузера.
  - Работает как в чистом Wayland, так и в X11 / Xwayland / Xephyr (совместимо с `oes-babl`).
- 🔄 **Интеллектуальная работа с раскладками (US / RU)**:
  - Автоматическое определение текущей раскладки рабочего стола (KDE Plasma DBus / X11).
  - Бесшовное переключение языка ввода без лишних нажатий клавиш.
  - Нормализация спецсимволов: типографические кавычки (`«»“”`), тире (`—–`), неразрывные пробелы.
- 🎯 **Безопасность фокуса и фоновый режим**:
  - Ввод направляется непосредственно в активный элемент текущего окна без перехвата фокуса.
  - Фоновый демон с глобальным хоткеем (`Ctrl+Alt+V`).
  - Управление через IPC-сокет (`mimictype trigger`, `mimictype stop`).
  - Аварийный выключатель (**Kill Switch**) по клавише `ESC`.

## Установка и требования

### Требования
- Linux (ядро с поддержкой модуля `uinput`)
- Python 3.10+
- `python-evdev`, `pyyaml`
- Доступ к `/dev/uinput` (членство в группе `input` или соответствующее udev-правило)
- `wl-clipboard` (для Wayland) или `xclip` (для X11)

### Установка
```bash
git clone https://github.com/BlaWhi3929BD/mimictype.git
cd mimictype
pip install -e .
```

## Использование

### 1. Прямой запуск (с обратным отсчетом)
Скопируйте текст в буфер обмена и запустите:
```bash
mimictype
```
Утилита даст 3 секунды, чтобы переключиться на нужное поле ввода, и начнет посимвольную печать.

Параметры:
```bash
# Ввод текста из аргумента с задержкой 2 сек на скорости 80 WPM
mimictype "Hello world!" -d 2 -w 80

# Использование пресетов: natural, fast, careful, instant
mimictype --preset fast

# Ввод из стандартного потока (pipe)
cat snippet.py | mimictype --stdin
```

### 2. Фоновый режим (Daemon с глобальным хоткеем)
Запустите демон в фоновом режиме:
```bash
mimictype daemon --hotkey ctrl+alt+v
```
Теперь вы можете выделить и скопировать любой текст, поставить курсор в целевое окно (например, Chrome в сессии `oes-babl`) и нажать `Ctrl+Alt+V`. Ввод начнется автоматически.

### 3. Управление через IPC
Если демон запущен, его можно запускать из скриптов, терминалов или горячих клавиш оконного менеджера:
```bash
# Немедленно начать печать буфера
mimictype trigger

# Напечатать конкретный текст
mimictype trigger "Пример текста"

# Узнать статус демона
mimictype status

# Остановить / прервать текущий набор
mimictype stop
```

### 4. Аварийный стоп (Kill Switch)
В любой момент во время печати нажмите клавишу **`ESC`** на физической клавиатуре. Утилита немедленно прервет набор и отпустит все клавиши.
